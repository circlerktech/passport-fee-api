Passport Fee API

Free, open, auto-updated passport and USPS shipping fees for U.S. passport acceptance facilities.

This API provides current U.S. passport application fees, USPS shipping rates, and delivery timeframes. Data is scraped weekly from official sources (U.S. Department of State and USPS) and updated automatically.

API Endpoints

GET fees.json — All fees, delivery times, and metadata
GET Fee-Schedule.pdf — Auto-generated PDF fee schedule

Quick Start

Embed the fee table on your website

Add this to any HTML page to display a live, auto-updating fee table:

<div id="passport-fees" data-show-pdf="true" data-show-updated="true"></div>
<script src="passport-fees.js"></script>

Fetch fees via JavaScript

fetch('fees.json')
  .then(r => r.json())
  .then(data => {
    console.log('Adult passport book:', data.fees.application.items.adult_book.amount);
    console.log('Priority Mail Express:', data.fees.shipping.items.priority_express.amount);
  });

Fetch fees via command line

curl -s fees.json | python -m json.tool

Inline Fee Replacement (Recommended)

Use passport-fees-inline.js to inject live fee values into your existing page. Add data-fee attributes to any element where a fee should appear:

1. Add the script to your page

<script src="https://circlerktech.github.io/passport-fee-api/passport-fees-inline.js"></script>

2. Use these span codes wherever a fee should appear

Application Fees

<span data-fee="application.adult_book"></span>          Adult Passport Book
<span data-fee="application.child_book"></span>          Child Passport Book
<span data-fee="application.adult_card"></span>          Adult Passport Card
<span data-fee="application.child_card"></span>          Child Passport Card
<span data-fee="application.adult_book_card"></span>     Adult Book + Card
<span data-fee="application.child_book_card"></span>     Child Book + Card

Execution & Photo Fees

<span data-fee="execution.execution_fee"></span>        Execution Fee
<span data-fee="execution.photo"></span>                 Passport Photo

Shipping Fees

<span data-fee="shipping.priority_express"></span>      Priority Mail Express
<span data-fee="shipping.priority_1_3_day"></span>      Priority Mail (1-3 Day)
<span data-fee="shipping.expedite"></span>              Expedite Fee

Delivery Times

<span data-fee="shipping.priority_express.delivery_time"></span>   "1-2 Days"
<span data-fee="shipping.priority_1_3_day.delivery_time"></span>   "1-3 Days"

Example

Priority Mail Express: <span data-fee="shipping.priority_express"></span>
(<span data-fee="shipping.priority_express.delivery_time"></span> delivery)

Renders as: Priority Mail Express: $33.25 (1-2 Days delivery)

Data Sources

  • Application fees — U.S. Department of State
  • USPS shipping rates — USPS Business Prices
  • Delivery timeframes — USPS Priority Mail Express / Priority Mail
